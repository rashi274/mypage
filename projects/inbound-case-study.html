AI-Powered Inbound Lead Routing & Enrichment Engine

Status: Live / Production-Ready Stack: GTM, Clay, HubSpot, Python, OpenAI

1. Executive Summary

Fast-growing SaaS business models rely heavily on operational speed. When inbound leads sign up, sales operations teams typically spend hours manually researching the lead's firmographics (company size, industry, revenue) before assigning them. This latency directly degrades sales conversion rates.

This project implements an automated, real-time lead ingestion and scoring pipeline. By combining Google Tag Manager triggers, a serverless Python middleware, Clay's waterfall enrichment API, and GPT-4o Mini for classification, the pipeline reduces lead-to-rep routing times from 4 hours to under 2 seconds.

2. Pipeline Architecture

Below is the data stream mapping. Website actions write to a standard browser-side dataLayer, which is dispatched via a Google Tag Manager webhook to a serverless backend. The backend manages external API connections (Clay, OpenAI, HubSpot) to finalize the flow. 

graph TD
    User[1. Website Signup Form] -->|JS Data Layer Push| GTM[2. Google Tag Manager]
    GTM -->|HTTP POST Webhook| Lambda[3. Serverless Python Script]
    Lambda -->|Retrieve Profile| Clay[4. Clay.com Waterfall API]
    Clay -->|Scrape / Lookup| LinkedIn[Clearbit / LinkedIn / ZoomInfo]
    LinkedIn -->|Return Data| Clay
    Clay -->|Enriched JSON| Lambda
    Lambda -->|Send Company Bio| LLM[5. GPT-4o Mini Classification]
    LLM -->|ICP Fit Yes / No| Lambda
    Lambda -->|Create Contact & Deal| CRM[6. HubSpot CRM]
    Lambda -->|Post Lead Alert| Slack[7. Slack #sales-alerts]

3. Technical Breakdown

Step 1: The Client-Side Data Layer

Instead of scraping DOM elements (which break when developers change CSS classes), we push event data to a virtual data layer. This is standard GTM best practice. 

window.dataLayer = window.dataLayer || [];
window.dataLayer.push({
  'event': 'inbound_lead_signup',
  'lead_email': 'alex.mercer@stripe.com',
  'signup_source': 'pricing_page_calculator',
  'context': {
    'ab_test_variant': 'variant_b'
  }
});

Step 2: Google Tag Manager Webhook Router

GTM listens for the inbound_lead_signup custom event, extracts the variables, and executes an asynchronous POST fetch request dispatching the data to our Python middleware endpoint. 

fetch('https://api.yourdomain.com/v1/inbound-lead', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    email: '{{dl_lead_email}}',
    source: '{{dl_signup_source}}',
    variant: '{{dl_ab_test_variant}}'
  })
});

Step 3: Clay.com Waterfall Enrichment

The webhook extracts the email domain and passes it to Clay. Clay queries data providers sequentially (Waterfall logic):

  • Provider 1 (Clearbit): Resolves company domain, employee count, and location.
  • Provider 2 (LinkedIn Company Scraper): If Clearbit returns null, Clay crawls the company's LinkedIn profile to extract employee count.

Step 4: AI Ideal Customer Profile (ICP) Classification

The serverless script passes the enriched company description to the OpenAI API (GPT-4o Mini) to check target fit.

System Prompt: You are a Sales Operations assistant. Evaluate if a company matches our Ideal Customer Profile (ICP). Our ICP Criteria: B2B SaaS, FinTech, or E-commerce company with more than 100 employees, OR any company that has raised a Seed round or above. Return JSON format: {"icp_fit": true/false, "reasoning": "..."}

def classify_company_icp(company_name, size, description):
    prompt = f"Company: {company_name}\nSize: {size}\nDescription: {description}"
    response = openai.chat.completions.create(
        model="gpt-4o-mini",
        response_format={"type": "json_object"},
        messages=[
            {"role": "system", "content": "Return JSON: {'icp_fit': bool, 'reasoning': str}"},
            {"role": "user", "content": prompt}
        ]
    )
    return json.loads(response.choices[0].message.content)

Step 5: HubSpot CRM Write-Back

If the company matches our ICP criteria, a new contact and deal are created dynamically in the CRM: 

def write_to_hubspot(email, name, company, size, title, icp_status):
    url = "https://api.hubapi.com/crm/v3/objects/contacts"
    headers = {
        "Authorization": "Bearer HUBSPOT_API_KEY",
        "Content-Type": "application/json"
    }
    payload = {
        "properties": {
            "email": email,
            "firstname": name.split(" ")[0],
            "lastname": name.split(" ")[1] if " " in name else "",
            "company": company,
            "company_size": size,
            "jobtitle": title,
            "icp_classification": "ICP_MATCH" if icp_status else "NON_ICP"
        }
    }
    requests.post(url, json=payload, headers=headers)
