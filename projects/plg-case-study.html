Product-Led Growth (PLG) Usage-Based Lead Scoring Engine

Status: Live / Operational Stack: GTM, Clay, Apollo, HubSpot, Python, Slack API

1. Executive Summary

Self-serve SaaS models often attract thousands of signups, but sales representatives cannot tell who is actively using the product vs. who just registered. Standard demographic lead scoring fails because a lead at a large company might never touch the software, while an active champion at a mid-market company is ready to buy.

This project builds an automated **Product-Led Growth (PLG) Lead Scoring Engine**. It captures live product usage events (such as adding team members or running analytics reports) via GTM, enriches the lead using Apollo & Clay waterfalls, calculates a combined **Product Qualified Lead (PQL)** score, creates HubSpot Deals, and dispatches real-time alerts to Slack.

2. System Architecture

Below is the data stream mapping. Product usage events are tracked in the application client-side, pushed to GTM, and processed by a serverless python script which calculates scoring, enriches data via Clay and Apollo APIs, and syncs status in HubSpot and Slack. 

graph TD
    User[1. User in SaaS App] -->|Trigger Usage Event| GTM[2. Google Tag Manager]
    GTM -->|HTTP POST Webhook| Lambda[3. Serverless Python Script]
    Lambda -->|Company Domain Lookup| Apollo[4. Apollo API Enrichment]
    Lambda -->|Waterfall Scraper| Clay[5. Clay.com Data Sync]
    Apollo & Clay -->|Return Firmographics| Lambda

    Scorer -->|PQL Score > 70| HubSpot[7. HubSpot PQL Stage Deal]
    Scorer -->|Push Alert Card| Slack[8. Slack #pql-alerts]

3. Step-by-Step Implementation

Step 1: Tracking Usage Events in the App

We track critical usage thresholds inside the product. When a user invites a teammate or approaches their API usage limits, we push the event to GTM's dataLayer: 

window.dataLayer = window.dataLayer || [];
window.dataLayer.push({
  'event': 'plg_usage_event',
  'lead_email': 'sarah@stripe.com',
  'action': 'invite_team_member',
  'quota_used_pct': 85
});

Step 2: Webhook Routing (GTM Server-Side Tag)

A webhook tag routes the dataLayer payload containing event details and quota data directly to our Python middleware endpoint.

Step 3: Sourcing Profile Data (Apollo & Clay)

The script extracts the email domain (e.g., stripe.com) and runs a parallel lookup: 1. **Apollo API**: Fetches company headcount, founding year, and industry. 2. **Clay API**: Scrapes company headcount directly from LinkedIn if Apollo records are incomplete.

Step 4: The Combined Lead Scoring Algorithm

We calculate a unified **Product Qualified Lead (PQL) Score** from 0 to 100 points, joining firmographic strength and product usage activity: 

def calculate_pql_score(company_size, industry, usage_action, quota_pct):
    score = 0
    
    # 1. Firmographic Scoring (Max 50 pts)
    if company_size >= 500:
        score += 30
    elif company_size >= 100:
        score += 20
        
    if industry.lower() in ["saas", "software", "fintech", "ecommerce"]:
        score += 20

    # 2. Product Usage Engagement Scoring (Max 50 pts)
    if usage_action == "invite_team_member":
        score += 25
    elif usage_action == "api_request":
        score += 10
        
    if quota_pct >= 80:
        score += 25 # High intent signal
        
    return score

Step 5: Dynamic HubSpot Deal Creation

When the score crosses 70 points, the lead is classified as a **Product Qualified Lead (PQL)**. The script creates or updates the Contact in HubSpot, maps the PQL Score, and opens a Deal in the "Product Qualified" stage: 

def create_hubspot_pql_deal(email, company_name, pql_score):
    url = "https://api.hubapi.com/crm/v3/objects/deals"
    headers = {
        "Authorization": "Bearer HUBSPOT_TOKEN",
        "Content-Type": "application/json"
    }
    payload = {
        "properties": {
            "dealname": f"PQL - {company_name}",
            "pipeline": "default",
            "dealstage": "appointmentscheduled", # Matches "Product Qualified" stage
            "amount": "1200", # Projected annual starter contract
            "pql_score": str(pql_score),
            "lead_email": email
        }
    }
    requests.post(url, json=payload, headers=headers)
